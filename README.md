# Threadhunt — лендинг

Отдельный публичный сайт-лендинг Threadhunt. **Никак не связан** с дашбордом — свой проект, свои зависимости.

Стек: Next.js (App Router) + Tailwind + статический экспорт (`output: 'export'`). Бренд «Lime-заряд» — тёмный минимализм, лаймовый акцент, Space Grotesk / Inter / JetBrains Mono. Полностью адаптивен под мобильные.

## Запуск (просмотр)

```bash
npm install
npm run dev      # → http://localhost:3000
```

## Сборка статики (для деплоя по ссылке)

```bash
npm run build    # кладёт готовый сайт в out/
npm run preview  # локально отдаёт out/ через `npx serve`
```

Папку `out/` можно открыть как файлы или залить на **любой** хостинг/CDN: Vercel, Netlify, Cloudflare Pages, GitHub Pages, S3.

## Что внутри

- **Hero** с живой анимацией «директ → совпадение → авто-ответ → лид» + бегущая строка кодовых слов.
- **Видео-блок** в анимированной рамке (вращающийся градиентный ореол).
- **Демо кабинета** — интерактивный обход (вкладки Обзор / Поиски / Кандидаты / Онбординг) в режиме «только просмотр»: кнопки отключены. Акцент на CRM, генераторе онбординга и уникальных ссылках.
- **Два режима запуска** — графический флоу: готовая воронка / кампания по шаблонам.
- **Bento возможностей** с живыми плитками (печатающийся ИИ-текст, анимированные графики, мини-чат).
- **Сравнение** «Вручную ↔ Threadhunt» (интерактивный переключатель).
- **Тарифы** с переключателями Месяц/Год (−17%) и валют ₽/$/€.
- **FAQ** — аккордеон с разбором «неудобных» вопросов (блокировки, ответственность, легальность, эмулятор).
- **Дисклеймер** про ответственность и эмуляцию + **юридические реквизиты** в подвале.
- **Светлая/тёмная тема** (переключатель в шапке, сохраняется в localStorage).
- **Запрет копирования** контента (контекстное меню, copy/cut/drag, горячие клавиши).
- **Cookie-баннер** согласия + страница `/privacy` с политикой конфиденциальности и cookie.

## Настройки

**Ссылки на кабинет** — кнопки «Войти» / «Начать бесплатно». Адрес в одной константе:
```ts
// components/Landing.tsx
const APP_URL = 'https://app.threadhunt.app';
```

**Видео** для блока «Посмотри, как это работает»:
1. Положи файлы `public/demo.mp4` и `public/demo-poster.jpg`.
2. В `components/Landing.tsx` переключи `const HAS_VIDEO = false` → `true`.

**Юридические реквизиты** — в `lib/legal.ts` (используются в подвале и на `/privacy`). Сейчас заполнены данными `TARGETPOINT AY` (Verona, Italia). Пустые поля скрываются автоматически.

## Режим запуска и лист ожидания

В `lib/config.ts`:
- `LAUNCHED = false` — **пред-запуск**: вместо регистрации все CTA ведут в форму листа ожидания, сайт закрыт от индексации (`noindex`). Готов к старту → поставь `true` и пересобери.
- `WAITLIST_ENDPOINT` — куда слать заявки. Пусто → **Netlify Forms** (если хостишь на Netlify, заявки придут сами). Иначе вставь URL Formspree/Getform/Tally.
- `PROMO` — промокод для первых (по умолчанию `EARLY50` · −50% на 2 месяца).

## Деплой (как вывести в онлайн)

**Netlify (рекомендуется — форма работает из коробки):**
1. `npm run build` → появится папка `out/`.
2. [app.netlify.com](https://app.netlify.com) → Add new site → Deploy manually → перетащи папку `out/`.
3. Сайт живёт на `имя.netlify.app`. Заявки листа ожидания → вкладка **Forms** (включи email-уведомления).
4. Свой домен: Site settings → Domain management → добавь домен и пропиши DNS.

**Через Git (авто-деплой):** запушь репозиторий на GitHub, подключи на Netlify/Vercel, build command `npm run build`, publish dir `out`.

**Vercel:** `npm i -g vercel` → `vercel` в папке. ⚠️ На Vercel нет Netlify Forms — задай `WAITLIST_ENDPOINT` (Formspree/Tally).

**Любой статик-хостинг/CDN:** залей содержимое `out/` в корень.
